# 项目目标与范围

本页维护已确认目标、范围和待决定事项。需求或范围变化时更新本页及对应设计；实际进度只维护在[当前状态](status.md)。[历史记录](archive/README.md)保留原始阶段说明。

## 已确认的目标
- 给伴侣的私人生日礼物：在熟悉的家里探索，通过物品触发回忆、简单互动和彩蛋。
- 体验重点是低门槛的虚拟游览和内容表达：保留小人物在微缩屋里走动，让观察与行走容易理解。2026-10-25 最新确认相对鼠标移动观察配合方向键行走，Esc 按当前互动层级退出。
- 最终通过电脑浏览器点链接打开，单人体验。以家的辨识度、宽敞感、舒适动线和漫画/卡通表达为先，模型比例服务于画面，照片参考重要元素与相对关系。
- 展示日期已确定为 2026-11-12（叶莹生日）。届时用户在德国，通过在线视频陪伴并引导她探索、呈现礼物；具体通话时间、视频工具和网页托管方式待定。
- 用户提供创意、审美、照片、故事和反馈；agent 完成建模、代码和验证。用户有编程基础，没有建模或游戏经验，不亲自写实现代码。
- 用户描述模糊体感时，agent 应主动说明对应的关键专业概念，用具体效果解释取舍，帮助用户理解游戏与交互设计。
- 创意和实现可以在多个对话同时推进，不要求先完成全部剧本。
- 用户已提供人物与关系背景；下一阶段由用户提出具体 idea，agent 基于背景讨论实现。讨论故事、彩蛋、角色或文案时读取 [背景入口](../references/background/README.md)，按任务再读全文与原始情书；背景主题不自动转为剧情、彩蛋或美术要求。
- 美术采用精致微缩小屋：柔和暖光、白色表面分层、家具接地、材质与造型统一；以实际浏览器样板对齐成品品质。人物、家具、镜头和动作共同设计，具体生产与尺度标准见 V2。
- 技术选型已确定为 Blender + Godot 标准版 / GDScript / Compatibility 渲染 / Web 导出；安装与操作说明以 [开发指南](guides/development.md) 为准。
- V2 探索镜头保持 40° 俯角和 35° 视野；点击开始游览后，鼠标左右移动量直接控制环绕，停手即停，WASD/方向键按当前画面移动，滚轮有限缩放。F 坐下时显示光标，Esc 优先起身返回游览；普通游览时 Esc 释放光标。探索观察点统一跟随角色，跨房间连续移动。五个坐位覆盖客厅软墩、长沙发中部/窗边、餐椅、书房椅。最新控制合同见 [相对鼠标游览与分层 Esc](design/mouse-look.md)，实际验证状态见 [当前状态](status.md)。
- 房间邻接与识别元素保留；布局、层高和家具尺寸按统一角色与实际动作重新制作。阳台保留空晾衣架、洗衣机朝向原照片；餐厅保留一把椅子与双开门冰箱；走道素墙；书桌和书柜留出重要道具展示面。

## 交互与彩蛋设计 V1

2026-10-17 已接入 [设计入口](design/README.md)及 9 份原稿：机制基线、7 个彩蛋设计稿、原包索引。机制 V1 和彩蛋入选已确认；各条目的具体内容、表现及待定事项继续审核。设计目标与已完成实现分开记录。

- 本对话最新确认：探索移动同时支持 **WASD 和方向键**，靠近后 F 交互；阅读时左右键翻页、Esc 退出，界面输入与角色移动隔离。背包图标可点击，鼠标选择物品与动作，重要操作尽量提供键盘替代。
- 入选彩蛋：E01 王冠、E02 生日蛋糕与生日仪式、E03 时间画册、E04 情书文集、E05 沙发猫抓痕、C01 2048、美食收藏图鉴（原 C02 已并入，见下方最新规则）。
- 情书指定篇章触发王冠获取提示，获取后自动佩戴，并可取下再戴；蛋糕从冰箱取出、摆到指定桌面、点燃蜡烛。两条流程独立，在生日仪式处汇合。
- 仪式须满足当前佩戴王冠、蛋糕已摆放、蜡烛已点燃，由玩家主动触发。其余彩蛋独立于仪式条件；本次游玩中的状态保持，跨刷新保存待定。
- 原稿及最新补充的阅读顺序、与现有技术/美术/空间范围的衔接见设计入口。各条目实际实现与验证以[当前状态](status.md)为准。
- 2026-10-26 确认[彩蛋实现路线](design/easter-egg-roadmap.md)：按五阶段推进，先打通情书、王冠与生日仪式；每阶段完整原型后集中打磨，Stage 1 不拆分中间用户验收。
- [Stage 1](design/stage-1-letters-crown.md) 制作完整的多篇正式情书文集，支持目录、分页、篇目跳转与本次阅读位置记忆，其中《理想主义与王冠》触发王冠获取。虚拟书保留小屋环境感，以书签为主、目录标记辅助引导；首版默认桌上阅读、确认领取后自动佩戴，支持取下与重戴。1366×768 下须同时满足全文清晰可读与环境可见性，执行者尽早在真实浏览器验证。

Stage 2 已批准按[蛋糕与生日仪式规格](design/stage-2-cake-ceremony.md)实施：餐厅准备蛋糕，玩家主动开始，演出可退出、结束后可返回或主动重播，准备状态在本次游玩保持。首版具体美术与镜头由 Agent 制作，用户待完整原型后集中调整。

E03 时间画册已批准进入 Stage 3 实施，当前合同见[时间画册 v1.4](design/stage-3-e03-time-album.md)及[时间轴组件](design/components/e03-timeline.md)：相册放客厅电视柜，2016–2025 用小舟，2026 用外形连续、内部双股的共同轨迹与暖光接力，历史／2026 按 60/40 → 20/80 原地伸缩，取消物理分合与通话针脚。照片与三处留白、成对脚印及“她走出第一步，剩下的路他来奔赴”保留；画册是私人回忆，不做刻意回避。已批准用示意素材实施，真实互动季度星群保留；本轮仅更新设计和 HTML，Godot v1.4 迁移及真实素材、部分年份和用户自选短句仍待后续。

C01 已批准按[茶几手机 2048 规格](design/c01-2048.md)实施：可选的独立小游戏，本次游玩保留棋局，刷新重置。

## 新增彩蛋：美食收藏图鉴

2026-10-29 确认[莹仔的美食收藏图鉴](design/food-collection/README.md)当前18款一屏自由贴纸拼贴设计：点击后打开左图右文详情，图鉴背景模糊；名称和介绍维护在共享内容JSON，布局按稳定ID关联。椰子卷、麦辣鸡翅已入选，街边小吃替代三文鱼；扣肉、千层面暂不纳入。原C02取消独立故事，以Pocky百奇条目呈现。发现任意第一种食物后激活，独立于生日仪式条件。

用户已追加批准游戏采用当前18款一屏与详情，替代旧16款滚动预览，共用内容和布局JSON，保留右下角图标／G和开发全收集预览。详情Esc先返回图鉴，再Esc返回小屋。正式探索已批准[Close-up方案](design/food-collection/close-up-interaction.md)：厨房开放，四区域分别发现；茶几包含食物和手机，座位归座椅；冰箱包含收藏食物与独立生日蛋糕动作。F打开详情才收录，未收集显示无名称淡色轮廓，收藏本机自动保存并可单独确认重置。实施与验证进度见[当前状态](status.md)。

2026-10-29 追加确认：厨房、零食柜、茶几各展示两样可辨认的立体代表美食；冰箱特写采用分层冷藏展示柜，生日蛋糕独立按钮取出，不参与普通食物焦点切换。四处特写支持鼠标点击、方向键与WASD选择，查看详情才收录。

## 已确认的全屋空间范围

2026-10-17 用户确认以下分级，作为后续建模、通行与互动范围的唯一权威清单。分级表示已选定的设计，不表示所有空间已经制作完成。

| 等级 | 空间 | 展示与游玩规则 |
| --- | --- | --- |
| 主要空间 | 客厅、餐厅、书房、走道 | 可以进入，是故事与互动的主要承载区域；已入选彩蛋见设计入口，具体落点待定。 |
| 次要空间 | 阳台、洗漱台 | 可以进入，保留代表性设施与空间氛围，不设置互动、互动标记或 F 提示。 |
| 新增主要互动空间 | 厨房 | 2026-10-29确认开放通行，复用已有模型，在灶台左侧台面进入食物特写；实际状态见[当前状态](status.md)。 |
| 不开放空间 | 其他所有空间 | 从开放区域只看见关闭的门，不展示内部、不提供开门互动、互动标记或操作提示。 |

“洗漱台”指布局图中的独立洗漱区，后方厕所不开放。卧室、杂物间等按关闭房门处理；隐藏区域内部的房间和房门不制作。

七个可见区域的制作范围及五个坐位要求见[场景规格](design/scene-v2.md)；各区域实际实现与验证统一见[当前状态](status.md)。

V2 以全局布局图保留空间关系，以餐厅成品样板统一全屋品质。主要与次要空间应构成可走通的路线；厨房按2026-10-29补充开放通行；关闭房门后不能窥见内部。空间分级继续有效。
