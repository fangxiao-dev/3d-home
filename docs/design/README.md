## 机制速览

- 体验重点：安静翻阅与发现内容，以及亲手完成生日仪式。日常细节可独立成立。
- 场景：点击进入游览，鼠标左右移动量控制环绕，停手即停；WASD / 方向键按当前画面移动，滚轮有限缩放。靠近后 F 交互并显示光标，Esc 优先退出当前互动；普通游览时 Esc 释放光标。最新机制见 [相对鼠标游览](mouse-look.md)。
- 界面：点击图标打开背包 / 人物状态，鼠标选中物品后选择动作；重要操作尽量提供键盘替代，具体快捷键待定。
- 阅读：左右键翻页，Esc 退出；进入界面切换输入上下文，本次游玩中的页码与物品状态保持。刷新或关闭后的存档方案待定。
- 物品：统一状态来源，按物件需要支持阅读、获取、佩戴、取下、摆放、激活或观察；场景、背包、人物示意图与事件条件同步。
- 王冠：《理想主义与王冠》触发获取提示；Stage 1 默认确认领取后自动佩戴，可取下再戴。书签和目录均可直达，详见 Stage 1 规格。
- 蛋糕：冰箱取出 → 指定桌面摆放 → 点燃蜡烛。具体表现及是否进入背包待定，无需预设自由搬运模拟。
- 仪式：**王冠当前已佩戴 + 蛋糕已摆放 + 蜡烛已点燃**，满足后由玩家主动开始；条件不足给反馈。王冠与蛋糕两条流程独立推进，在仪式处汇合。
- 时间画册、猫抓痕、2048、美食图鉴均不是仪式条件。仪式镜头、音乐、台词、结束与重播行为待定。

## 与现有项目的衔接

- 原稿称技术路线可调整、最终美术和尺寸待定。项目已确认 Blender + Godot / GDScript / Compatibility / Web，以及清爽暖光、宽敞卡通比例；这些已有决定继续有效，具体道具造型和角色表现仍待深化。
- 原稿列 WASD，当前玩法文档列方向键。本页最新确认已合并为两套移动键；实际代码是否已支持两套，按后续实现与浏览器验收记录判断。
- 原稿对时间画册同时写了实体阅读物及“时间长廊 / 相册 / 组合形式待定”。保留阅读与翻页目标，最终呈现仍待确定，不自动扩建 3D 长廊。
- 已有软墩查看与沙发坐位是当前实现。E05 的抓痕观察不能自动等同于这几个入口，具体绑定位置与方式待确认。
- 冰箱与桌面的落点要结合全屋空间范围设计：主要空间可互动，厨房仅可见且不可进入，阳台和洗漱区可进入但无互动。原稿没有授权修改空间分级。
- 背景和素材从 [参考资料入口](../../references/README.md)查找。情书收录与台词引用需核对原文和叙述者；已入选“情书文集”并不等于全部私人资料均获准放进成品。
