## 目标与决定

保留小人物和微缩小屋。鼠标负责观察，WASD/方向键按当前画面方向行走；不增加第一人称、点击寻路或内容互动。

- 左右边缘连续环绕，无需按键。触发带各为画布宽度 8%，限制在 48–120 px；停留 150 ms 后启动，150 ms 渐入，越靠外越快，最高 45°/秒。右边缘向右观察，左边缘反向，支持完整一圈。
- 中间不转；移回中间、离开画布或窗口失焦及时停止。首次加载、重新获得焦点或退出坐姿后，鼠标先经过中央区域才重新激活。操作提示面板不触发转向。
- 坐起及自动接近/退出期间隔离环绕、缩放和探索输入。坐姿保持设计近景，退出平缓恢复先前角度与缩放。
- 移除 Q/E 的 90°切换。人物按当前实际镜头方位移动，转身不带动镜头。
- 探索观察点为角色脚底上方 0.8 m；以每秒 8 的响应系数单次平滑跟随。移除房间中心混合和房间取景钳制；同一观察点和角度生成镜头位置与朝向。
- 保留俯角 40°、FOV 35°、基础距离 10.5 m、缩放 0.85–1.15。只开放水平环绕。
- 更新操作文字，边缘触发时显示轻微方向提示；现有遮挡扩展连续角度验证，修复实际暴露问题。本轮不另做墙体淡出效果。
