## 已确认行为

- 固定场景内一次 Esc 只起身退出并恢复游览；外层游览另一次 Esc 才暂停、释放光标并显示“继续游览”。一次按键不能跨状态重复消费，长按与重复事件不重复启动动作。
- 自动走近和人物对齐保持原流程。准备就绪后，0.15 秒淡出；完全遮黑时切到该坐位现有固定镜头并更新遮挡；0.20 秒淡入；画面完全显现后才播放 SitDown。每个坐位各有固定构图，与进入时游览角度、缩放无关。
- 退出恢复进入前的游览角度和缩放，沿用既有返回过渡。正常退出并成功捕获时不显示继续按钮；初次进入、外层暂停、失焦和浏览器拒绝捕获保留既有手动恢复。
- 淡化与坐起期间隔离探索输入；恢复前需松开持续按住的移动键。退出遇阻仍回坐并显示光标，保留重试。
- 保留当前纯色材质、模型、碰撞、坐位、灯光、烘焙和画质。不新增互动、菜单或通用转场框架。
