# Stage 1：情书与王冠体验规格

2026-10-26 已确认。本文是 E04 情书文集与 E01 王冠在第一阶段的最新体验依据，优先于 V0.1 原稿中的对应待定项。整体顺序见[彩蛋实现路线](easter-egg-roadmap.md)，实际实现与验证统一见[当前状态](../status.md)。

## 目标与交付方式

交付一套真正可阅读的多篇情书文集，包含目录、篇目跳转、分页与本次阅读位置记忆。《理想主义与王冠》是其中带有特殊互动的一篇。

完整体验链：发现文集 → 打开虚拟书并自由阅读多篇情书 → 通过书签、目录或翻页访问《理想主义与王冠》 → 领取并自动佩戴王冠 → 在人物／背包界面取下与重新佩戴 → 返回游览。

一次实现完整可玩的原型，再由用户对着画面集中调整，不拆分中间用户验收。执行者先给出书本构图、字体、纸张、书签颜色、王冠造型与反馈的完整方案。

## 玩家体验

### 在小屋里打开情书

场景中有可接近、可辨认的实体文集。靠近后明确提示按 F 打开情书，与旁边坐位的交互可区分。

打开后书本成为阅读焦点，仍保留周围环境、空间感与书的实体感。不能把整个屏幕替换为书页或纯文字阅读器；要有在小屋里拿着或放在桌上阅读的感觉。第一版默认采用桌上阅读，具体构图根据试玩调整。文字清晰、完整可读，装饰不挤占必要阅读空间。

文字不必实际渲染在 3D 纸张表面，可以使用视觉上融合于场景的阅读 UI。书、桌面与周围环境提供空间感，文字呈现保证清晰度。长文通过增加页数完整呈现，不靠缩小字号迁就书页造型。

### 书签、目录与翻页

- 书签是主要引导：从书页边缘露出，带小王冠标记，点击直达《理想主义与王冠》。
- 目录提供全部收录篇目的导航与跳转；《理想主义与王冠》旁使用同样的小王冠标记，辅助发现特殊内容。目录只展示实际收录内容。
- 书签、目录和普通翻页均可到达同一篇内容，触发相同的王冠获取流程。
- 引导容易注意到，并保留私人文集气质；第一版不使用持续强闪烁或强制弹窗催促阅读。

### 阅读与获得王冠

Stage 1 收录本地归档的 15 篇非草稿正文及相关 7 张图片，包括信件、留言和回忆记录；按归档顺序排列。排除根索引与两个草稿箱，当前快照未发现重复内容哈希。保留原文，提供目录、分页、篇目跳转与本次阅读位置记忆，不擅自删改或润色。

《理想主义与王冠》全文是确定的触发篇章，使用[本地原文](../../references/love-letters/子文档/11-理想主义与王冠-260423X.md)。文集来源为 2026-10-16 离线快照，通过只读 junction 访问；允许分页排版，不擅自改写正文。

进入该篇即出现获取提示，不要求读完全文、等待计时或读完整本文集。第一版默认提供明确的“领取王冠”操作，领取后自动佩戴；玩家可先继续阅读，之后仍能领取。

反馈与文章自然相连，表达来自文集的私人赠予，而非通关奖励。重复进入不会重复发放，也不会持续打断阅读。

### 查看、取下与重新佩戴

退出阅读后能看到角色头上的王冠。人物／背包界面提供直接快捷入口，可辨认当前佩戴状态并执行取下或重新佩戴。取下只改变佩戴状态，不丢失物品。

界面状态、人物示意与场景角色外观保持一致。当前佩戴状态供 Stage 2 的生日仪式使用。

### 鼠标与键盘

- 游览时隐藏光标，鼠标控制视角，WASD／方向键移动。
- 阅读与人物／背包界面打开时显示光标，暂停角色移动和游览镜头控制。
- 鼠标可点击书签、目录、翻页与物品操作；保留左右键翻页、Esc 退出和重要操作的键盘入口。
- Esc 优先退出当前互动，一次按键不会连续关闭多层并意外暂停。
- 返回游览后恢复操作；浏览器未恢复鼠标捕获时，提供明确的点击继续入口。

## 验收标准

| 维度 | 通过条件 |
| --- | --- |
| 发现与到达 | 玩家从正常游览找到文集、打开阅读，通过明显书签进入指定篇章，无需开发者指路或调试入口 |
| 文集完整性 | 本地正式情书均已核对并收录，目录与实际篇目对应；根索引、草稿箱、重复版本的处理有明确记录 |
| 导航完整性 | 所有收录篇目可从目录访问并完整翻阅；书签、目录、普通翻页均可到达触发篇章；其他页面与退出入口始终可用 |
| 阅读质量 | 所有收录文章在 1366×768、浏览器默认缩放下，通过翻页完整可读，无缺字、缺段、裁切或重叠，无需放大浏览器或横向滚动；退出再打开保留本次阅读篇目与页码 |
| 空间感 | 同一阅读状态下，阅读区域周围仍有可辨认的小屋环境，书与桌面有可理解的空间关系；文字清晰度与环境可见性同时满足 |
| 获取流程 | 指定篇章触发获取机会，领取后自动佩戴；暂不领取不会永久错过，重复访问不会重复发放 |
| 物品操作 | 取下与重新佩戴均可完成；界面和角色外观同步，关闭界面不重置状态 |
| 操作连续性 | 阅读翻页不会移动角色，点击界面不会转动镜头；退出后可继续行走、坐下和起身 |
| 原意保留 | 情书保留原本语气；王冠关联文章中的赠予与关系表达，不包装成阅读考试、任务奖励或通用公主装饰 |
| 完整交付 | 实际网页中完成发现文集、阅读、领取、佩戴、取下、再佩戴、返回游览的完整链路，并交付原型供用户集中反馈 |

执行者检查功能可达性，并完成一次聚焦独立审查；用户通过完整原型判断阅读氛围、王冠反馈与私人表达。功能通过不等于审美和表达最终定稿。

### 尽早验证阅读形式

阅读形式初步可用后，执行者即在真实浏览器的 1366×768、默认缩放下使用实际原文检查中文清晰度、长段落、分页、篇目切换与环境可见性，发现问题立即调整，再继续整合王冠与背包。不能等全部功能完成后才首次验证阅读形式，也不能只验证触发篇章。最终检查覆盖全部收录文章的内容完整性与页面可达性。

这是执行者内部验证，不增加中途用户验收。明显的字号过小、模糊、翻页困难或书页遮满屏幕的问题应在交付前处理；舒适度与氛围由用户在完整原型中继续调整。

## 第一版范围

桌上阅读、王冠书签、目录标记、确认领取是可调整默认值；用户根据实际画面统一反馈。仅保证本次游玩中的阅读与王冠状态，跨刷新存档不作为本阶段完成条件。

本阶段不制作蛋糕与仪式，不新增自由抓取、手持搬运或完整装备系统。源情书保持只读，公开上传私人素材仍需明确授权。
