# Stage 2：蛋糕与生日仪式

2026-10-27 用户批准实施。本文为 E02 的首版体验与验收依据，补充 V0.1 中的操作、结束与重播选择；实际进度见[当前状态](../status.md)。

## 体验与范围

玩家在现有餐厅冰箱取出蛋糕，摆到餐桌指定位置，点燃蜡烛；当前戴着王冠时，由玩家主动开始生日仪式。蛋糕与王冠可以任意顺序准备，其他彩蛋不作为门槛。

首版通过明确的 F 提示与场景变化表达取出、摆放和点燃，不要求自由搬运、手持行走或蛋糕进入背包。冰箱取出后提供清楚的已取出反馈，桌面显示蛋糕，点燃后有可见烛光；重复输入不复制或重置道具。未满足条件时给出对应下一步提示。

仪式具有明确开始、生日呈现和结束，人物、蛋糕与烛光同框，用简短“生日快乐”表达祝福。首版美术与镜头由 builder 制作并由主控验收，不新增私人故事或承诺。具体音乐并非首版完成条件，音效如采用须可本地合法使用。

仪式结束提供返回游览与主动重播，Esc 可退出演出，保留蛋糕和王冠准备进度；重播仍检查当前王冠佩戴条件。演出中隔离游览与背包操作，失焦暂停演出，恢复通过明确的继续入口，不自行抢回鼠标。一次按键只执行当前动作，不连跳多个准备步骤。

本次游玩保持状态，刷新重新开始。厨房维持仅展示范围，不制作烘焙、切分、分发或收集任务。一次交付完整原型后由用户集中微调，无中途用户验收。

## 执行与验收责任

builder 负责资产、运行逻辑、必要测试、构建导出和实际网页证据；先验证自然入口再扩充演出。独立 reviewer 与 builder 必须是不同 agent，逐项检查上述标准并复核失败修复。主控消费截图、操作结果和审查结论，判断玩家可达性与仪式表达，不重复全部底层执行。

全部必验项通过后才宣布 Stage 2 完成。工具中断则保留未验收项，继续可独立完成的工作；不给用户默认分配功能补测。交付为本地试玩，公开上传、提交和推送另行授权。
