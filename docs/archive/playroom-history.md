# 游玩操作与验收

当前采用 [相对鼠标游览与分层 Esc](design/mouse-look.md)，最新转场规则见 [固定场景转场](design/fixed-scene-transition.md)，保留 [成品场景 V2](design/scene-v2.md) 的小人物、微缩屋与纯色材质。当前资源版本、实际验证范围及性能边界统一见 [HOUSE.md](HOUSE.md)。

## V2 操作

| 操作 | 效果 |
| --- | --- |
| 点击“开始游览／继续游览” | 隐藏并锁定光标，成功后进入游览。 |
| WASD / 方向键 | 按当前画面方向行走，松开停止。 |
| 左右移动鼠标 | 按移动量水平环绕观察，停手即停；无需按住鼠标或移回中央。 |
| 滚轮 | 在有限范围内拉近或拉远。 |
| 靠近坐位后 F | 走近对齐后短暂淡出，再从该坐位固定近景淡入；画面显现后坐下，光标可见。 |
| 坐下后 Esc | 起身退出互动，直接恢复探索镜头与游览控制，无需再点继续。 |
| 普通游览时 Esc | 释放光标，停止玩家操控；点击“继续游览”恢复。 |

五个坐位：入口软墩、长沙发中部、窗边坐位、餐椅、书房椅。附近提示说明 F 对应的唯一目标。坐起过渡中锁定探索输入；恢复后先松开持续按住的移动键再移动。

每个坐位使用自己的预设机位：淡出 0.15 秒，完全遮黑时切镜头，淡入 0.20 秒后开始坐下动作；进入前的游览角度与缩放不改变该构图。退出恢复进入前的游览视角。一次 Esc 只处理当前一层：正常起身返回后，需再次按 Esc 才暂停游览。

首次打开、主动释放鼠标或窗口失焦后，点击按钮才能进入游览。切回页面不会自动接管鼠标。坐姿的程序性释放允许退出互动时恢复控制；若期间失焦或未能恢复锁定，完成起身后点击“继续游览”。坐起过渡隔离探索输入，原来按住的移动键需先松开。俯角保持稳定，上下鼠标移动不改变俯角；跨区域只跟随人物位置，不按房间中心重新取景。

本阶段的通用人物使用独立骨骼与五种动画，坐位读取资产中的接近、坐姿根、退出和镜头数据。人物不通过改变体型适应家具。后续抓痕、阅读与生日仪式按 V1 另行实现。

## V2 验收

- 7 区画面，6 区可达，厨房和关闭房间保持阻挡。
- 连续环绕、每 45°机位、近远缩放及跨门洞镜头，检查人物可见性与建筑附件；30°、135°、270°下移动方向与画面一致。
- 5 坐位各至少 3 次坐起，验证臀部、手脚、膝部、起身轨迹与安全出口。
- WASD/方向键、F/Esc、长按与重复按键，坐起期间的输入隔离。
- Chrome 两分辨率和 10 分钟连续探索；只报告实测显卡与性能。
- 真实点击捕获、等位移等转角、停手无漂移、Esc 分层退出、失焦后手动继续、拒绝捕获与恢复、坐起过渡及长按隔离；原问题路线仍为只按下方向键跨越客厅→走道→餐厅并往返。当前测试入口为 [fixed-scene-transition](verification/fixed-scene-transition-20261025/)，旧边缘和四向镜头证据适用于各自的历史资源版本。

上表验收范围与每轮实际完成量分开记录，当前结果见 [HOUSE](HOUSE.md)。历史导航包 1a42 的两分辨率十次坐起、224 组视角和十分钟游览，以及更早版本的三十次坐起，均保留原版本归属，不计作新控制的实际运行次数。
