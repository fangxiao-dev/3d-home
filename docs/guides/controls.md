# 游玩操作

操作机制改变时更新本页；当前实现和已知问题见[状态](../status.md)，详细要求从[设计入口](../design/README.md)进入。

## 游览与互动

| 操作 | 效果 |
| --- | --- |
| 点击“开始游览／继续游览” | 隐藏并锁定光标，成功后进入游览。 |
| WASD / 方向键 | 按当前画面方向行走，松开停止。 |
| 左右移动鼠标 | 按移动量水平环绕观察，停手即停；无需按住鼠标或移回中央。 |
| 滚轮 | 在有限范围内拉近或拉远。 |
| 靠近坐位后 F | 走近对齐后短暂淡出，再从该坐位固定近景淡入；画面显现后坐下，光标可见。 |
| 坐下后 Esc | 起身退出互动，直接恢复探索镜头与游览控制，无需再点继续。 |
| 普通游览时 Esc | 释放光标，停止玩家操控；点击“继续游览”恢复。 |

## 情书与王冠

用户已手动体验并确认大致通过；具体证据边界见[当前状态](../status.md)。

- 走到书房书桌的文集旁，按提示使用 F 打开阅读。提示区分情书与书房坐位。
- 点击目录篇目或王冠书签阅读，左右键／翻页按钮翻页；本次游玩保留阅读位置。
- 进入《理想主义与王冠》后可点击领取王冠，领取后自动佩戴；可稍后返回领取。
- B 打开人物／背包界面，也有可点击入口；领取后可取下或重新佩戴。
- 阅读或背包内显示光标并隔离行走与转镜头；Esc 关闭当前界面，必要时点击继续游览恢复鼠标捕获。
- 本次游玩中的王冠状态保持，刷新网页会重新开始。

## Stage 2 候选操作

蛋糕与仪式已接入本地候选，引擎检查通过，真实网页验收尚待完成。

- 靠近餐厅冰箱，按 F 取出蛋糕；走到餐桌指定位置按 F 摆放，再按 F 点燃蜡烛。每次按键只完成一步。
- 王冠与蛋糕可任意顺序准备；当前戴着王冠、蛋糕已摆放且蜡烛点燃后，餐桌处 F 主动开始庆祝。缺条件时提示下一步。
- 演出约 8 秒，结束后可返回游览或点击“再庆祝一次”；Esc 可随时退出并保留准备状态。
- 失焦会暂停庆祝，回到页面后明确点击“继续庆祝”；Enter 可继续暂停的仪式，或在结束后重播。
- 演出期间隔离行走、镜头、F 与 B；返回后恢复游览，鼠标未捕获时点击继续游览。
- 进度仅在本次游玩保持，刷新重新开始。

## 茶几手机 2048 候选操作

- 靠近客厅茶几，出现“F 玩手机 · 2048”后按 F 进入。方向键每按一次移动一步，长按不连发。
- 合并相同数字并累计分数；达到 2048 后可继续，无合法移动时可重新开始。
- “重新开始”可鼠标点击，也可 Tab／Enter 操作；已有进度时先确认，Esc 先取消确认，再退出小游戏。
- 离开后再次进入保留本局棋盘和分数，刷新重置。小游戏独立于王冠、蛋糕和仪式。
- 失焦后点击“继续游戏”；退出后的鼠标捕获失败时，点击“继续游览”。真实网页验收状态见[当前状态](../status.md)。

## 时间画册

- 靠近客厅电视下方柜面的相册，出现“F 翻开时间画册”后按 F 阅读。
- 左右方向键或按钮翻页；点击底部记忆圆点跳转，时间轴边缘圆点可跨越 2025／2026。两颗早年聊天亮星悬停显示短句，季度星群只作光影表达。
- Esc 或“合上相册”返回游览；本次游玩记住阅读单元，刷新重置。失焦后退出不会自动捕获鼠标，点击“继续游览”恢复。
- 示意配图与待核实年份仍待替换；时间画册独立于其他彩蛋和生日仪式。

## 原有坐位与游览细节

五个坐位：入口软墩、长沙发中部、窗边坐位、餐椅、书房椅。附近提示说明 F 对应的唯一目标。坐起过渡中锁定探索输入；恢复后先松开持续按住的移动键再移动。

每个坐位使用自己的预设机位：淡出 0.15 秒，完全遮黑时切镜头，淡入 0.20 秒后开始坐下动作；进入前的游览角度与缩放不改变该构图。退出恢复进入前的游览视角。一次 Esc 只处理当前一层：正常起身返回后，需再次按 Esc 才暂停游览。

首次打开、主动释放鼠标或窗口失焦后，点击按钮才能进入游览。切回页面不会自动接管鼠标。坐姿的程序性释放允许退出互动时恢复控制；若期间失焦或未能恢复锁定，完成起身后点击“继续游览”。坐起过渡隔离探索输入，原来按住的移动键需先松开。俯角保持稳定，上下鼠标移动不改变俯角；跨区域只跟随人物位置，不按房间中心重新取景。

通用人物使用独立骨骼与五种动画，坐位读取资产中的接近、坐姿根、退出和镜头数据。人物不通过改变体型适应家具。抓痕等其他彩蛋按后续阶段实现。
