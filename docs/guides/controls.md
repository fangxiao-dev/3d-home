# 游玩操作

操作机制改变时更新本页；当前实现和已知问题见[状态](../status.md)，详细要求从[设计入口](../design/README.md)进入。

## 游览与互动

| 操作 | 效果 |
| --- | --- |
| 点击“开始游览／继续游览” | 隐藏并锁定光标，成功后进入游览。 |
| WASD / 方向键 | 按当前画面方向行走，松开停止。 |
| 左右移动鼠标 | 按移动量水平环绕观察，停手即停；无需按住鼠标或移回中央。 |
| 滚轮 | 在有限范围内拉近或拉远。 |
| 靠近坐位后 F | 走近对齐后短暂淡出，再从该坐位固定近景淡入；画面显现后坐下，光标可见。 |
| 坐下后 Esc | 起身退出互动，直接恢复探索镜头与游览控制，无需再点继续。 |
| 普通游览时 Esc | 释放光标，停止玩家操控；点击“继续游览”恢复。 |

五个坐位：入口软墩、长沙发中部、窗边坐位、餐椅、书房椅。附近提示说明 F 对应的唯一目标。坐起过渡中锁定探索输入；恢复后先松开持续按住的移动键再移动。

每个坐位使用自己的预设机位：淡出 0.15 秒，完全遮黑时切镜头，淡入 0.20 秒后开始坐下动作；进入前的游览角度与缩放不改变该构图。退出恢复进入前的游览视角。一次 Esc 只处理当前一层：正常起身返回后，需再次按 Esc 才暂停游览。

首次打开、主动释放鼠标或窗口失焦后，点击按钮才能进入游览。切回页面不会自动接管鼠标。坐姿的程序性释放允许退出互动时恢复控制；若期间失焦或未能恢复锁定，完成起身后点击“继续游览”。坐起过渡隔离探索输入，原来按住的移动键需先松开。俯角保持稳定，上下鼠标移动不改变俯角；跨区域只跟随人物位置，不按房间中心重新取景。

本阶段的通用人物使用独立骨骼与五种动画，坐位读取资产中的接近、坐姿根、退出和镜头数据。人物不通过改变体型适应家具。后续抓痕、阅读与生日仪式按 V1 另行实现。
