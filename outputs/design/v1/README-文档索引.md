# 生日礼物｜设计稿包

本包包含一份项目设计基线与 Session 决策记录，以及 7
份独立彩蛋设计稿。它们用于并行审核，不等同于最终 PRD 或技术实现规格。

## 文件索引

  --------------------------------------------------------------------------------
  文件                                用途
  ----------------------------------- --------------------------------------------
  `00-项目设计基线与Session决策.md`   项目定位、协作原则、交互机制
                                      V1、生命周期规则、生日仪式条件、待决策事项

  `01-E01-王冠.md`                    王冠获取、佩戴状态与生日仪式关联

  `02-E02-生日蛋糕与生日仪式.md`      蛋糕状态、准备流程与仪式触发条件

  `03-E03-时间画册.md`                时间画册的体验目标、内容定位与阅读机制

  `04-E04-情书文集.md`                情书来源、阅读机制与王冠获取提示

  `05-E05-沙发猫抓痕.md`              近距离环境彩蛋

  `06-C01-2048.md`                    2048 日常记忆彩蛋

  `07-C02-百醇.md`                    百醇日常记忆彩蛋
  --------------------------------------------------------------------------------

## 审核建议

建议先审核
`00`，确认整体规则和已冻结决策没有遗漏或误读；随后可以并行审核各彩蛋设计稿。

每份彩蛋稿区分已确定事项、推荐方案和待决策项。推荐方案不是自动冻结的需求；如需调整，可直接针对对应文件提出修改意见。
