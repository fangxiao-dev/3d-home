# 客厅游玩与镜头验收

本机试玩：<http://127.0.0.1:8767/?v=wide-room>

## 操作

| 操作 | 效果 |
| --- | --- |
| 方向键 | 按画面方向移动，松开停止。 |
| Q / E | 逆时针 / 顺时针旋转 90°；长按只转一次。 |
| 滚轮向上 / 向下 | 拉近 / 拉远，范围为默认距离的 85%–115%。 |
| 靠近入口软墩，按 F | 切到固定近景查看坐面，隐藏人物。 |
| 靠近长沙发中部或窗边坐位，按 F | 临时小人坐下，切到人物正面的固定镜头。 |
| 固定镜头中按 Esc | 返回进入前的位置、朝向、镜头角度与缩放，恢复站姿。 |

寻找三处小标记：入口奶油色软墩一处，长沙发中部和窗边各一处。靠近且未被家具遮挡时，只有最近的可用目标显示 F 提示。若键盘没有响应，先点击游戏画面。

固定镜头和切换期间锁定方向键、Q/E、滚轮及重复 F；退出时若还按着方向键，先松开再移动。本轮人物为临时造型，坐姿采用简单屈腿表达；软墩上尚未制作正式划痕。

## 场景与镜头

客厅采用 5.8 m 内宽、5.8 m 纵深、3.3 m 层高的画面尺度。两侧墙与家具组各向外平移 0.75 m，家具大小不变，中央留白增大。前景座位是宽 0.86 m 的无靠背奶油色软墩；长沙发前的两把木椅已移除，落地灯为静态装饰。保持明亮暖光，环境不投影，探索时人物有脚下阴影。

探索镜头水平距离默认 3.6 m，相对水平面向下约 29°，视野 62°；这是原低机位约 19° 再增加 10°。缩放同步调整高度以保持俯角。近侧墙窗按镜头位置隐藏；建筑与吊灯按机位处理遮挡，碰撞仍保留。三个互动点与固定机位随家具平移，保持原有相对构图。

坐下仅改变人物视觉位置与姿态，探索碰撞体留在原地并停止运动，退出时恢复人物所有视觉变换。进入固定镜头时取消未完成的旋转与缩放，防止退出后继续旧动作。

## 重建

当前入口为 `godot/playroom.tscn`，控制与互动逻辑为 `godot/playroom.gd`。修改代码后运行 `Build.ps1`；修改模型后运行 `Build.ps1 -RebuildModel`，同步 Blender、GLB、离线预览及网页。

## 验收清单

- 四个方向视野清楚；近、默认、远缩放均保持约 29°，顶面和吊灯不明显遮挡人物。
- 软墩无靠背、无扶手；两把木椅及碰撞消失，原椅子位置可以走过，保留家具仍阻挡人物。
- 从出生点真实走到三处标记：软墩可查看，两个坐位都可坐，简化坐姿没有明显穿模。
- 靠近出现唯一可用 F 提示，隔着家具不能触发；固定镜头内标记隐藏。
- 固定镜头操作锁定，Esc 准确恢复；反复进入退出、长按及切换时按键不会漂移或重复触发。
- 落地灯无交互提示，F 不改变其状态。
