# 生日礼物 · 3D 小屋

在熟悉的微缩小屋里控制人物、探索并发现回忆。使用 Blender 制作资产，Godot 运行，电脑浏览器试玩。

## 打开试玩

在项目根目录执行 `./scripts/Start-Preview.ps1`，打开 <http://127.0.0.1:8767/>，点击“开始游览”。已有服务时直接打开地址；更多操作和构建方式从[文档导航](docs/README.md)进入。
