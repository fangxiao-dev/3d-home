# 生日礼物 · 3D 小屋

这是一份为伴侣制作的生日礼物：把熟悉的家做成可以走进去游览的微缩小屋，在房间、家具和日常物件中承载两个人的回忆。

玩家可以看见小人物在屋里走动，移动鼠标观察周围，靠近物品进行互动。项目优先考虑自然、容易理解的操作，以及场景里的内容表达；最终希望通过电脑浏览器打开链接即可体验。

用户提供创意、故事、照片与试玩反馈，agent 负责建模、实现和验证。场景资产使用 Blender 制作，游戏使用 Godot / GDScript 与 Compatibility 渲染，导出为网页。

## 现在能体验什么

目前已完成小屋的基础游览：客厅、餐厅、书房、走道、阳台和洗漱区可以走入，厨房作为可见的展示空间；人物可以在五个坐位坐下，再起身返回游览。

围绕王冠、生日蛋糕、时间画册、情书等内容的彩蛋已经有设计，仍需继续深化和实现。当前可试玩版本、已知问题及下一步统一记录在[当前状态](docs/status.md)，这里保留体验概览。

## 打开试玩

在已准备好工具、已有网页导出的本机环境中，从项目根目录运行：

```powershell
./scripts/Start-Preview.ps1
```

在 Chrome 打开 <http://127.0.0.1:8767/>，点击“开始游览”。已有预览服务时直接打开地址即可。这个地址仅供本机使用，网页托管尚未确定。

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 按画面方向行走 |
| 左右移动鼠标 | 环绕观察，停手即停 |
| 滚轮 | 拉近或拉远 |
| 靠近坐位后按 F | 自动走近，从预设镜头进入坐姿 |
| 坐姿中按 Esc | 起身并直接返回游览 |
| 游览中按 Esc | 释放鼠标并暂停，点击“继续游览”恢复 |

首次克隆不会附带网页导出和本机工具配置。需要准备环境、重新构建或排查启动问题时，从下方文档导航进入开发指南。

## 目录结构

```text
docs/          项目文档：目标、状态、设计、架构、指南与历史档案
godot/         游戏工程、运行逻辑和必要资源
blender/       可编辑模型、公共规格及资产生成脚本
scripts/       构建、烘焙与本地预览入口
tests/         现役验证脚本及使用说明
references/    背景资料、素材说明与外部原始素材链接
outputs/       生成的网页与预览画面
work/          本机工具、缓存、日志和临时调查
```

`godot/` 与 `blender/` 中的源文件和必要运行资源随仓库保存；`outputs/`、`work/` 中的生成产物和本机配置按忽略规则保留在本地。详细目录职责和资源生成流程从文档导航中的架构概览查看。

## 素材与发布

房屋照片和原始情书通过 `references/` 下的目录链接访问，原件保留在外部素材盘，不复制进仓库，也不随网页打包。仓库包含用于协作的背景整理与设计文档。

可部署网页的范围为 `outputs/web/`。本地能试玩、已生成可部署文件和已经上线是不同状态，实际进展以当前状态文档为准。
